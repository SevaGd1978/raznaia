# Готовый MTProto-прокси для Telegram

Свой прокси на VPS через [mtg](https://github.com/9seconds/mtg) + Docker.  
Трафик маскируется под HTTPS (Fake-TLS) — удобно там, где Telegram режут DPI.

> Случайные «бесплатные прокси из интернета» небезопасны и быстро умирают.  
> Здесь — **ваш** прокси: секрет только у вас, ссылка для Telegram сразу после установки.

## Что нужно

- VPS (Ubuntu/Debian), от ~512 MB RAM
- Открытый порт **443** (или другой, если 443 занят)
- Root / sudo

## Быстрый старт

```bash
git clone <этот-репозиторий> telegram-proxy
cd telegram-proxy
chmod +x setup.sh
./setup.sh
```

Скрипт:

1. Установит Docker (если его нет)
2. Сгенерирует Fake-TLS секрет
3. Поднимет контейнер `nineseconds/mtg:2`
4. Выведет ссылку вида `tg://proxy?server=...&port=443&secret=ee...`

Откройте ссылку на телефоне/ПК с установленным Telegram — прокси добавится сам.

Позже:

```bash
./setup.sh link       # снова показать ссылку
./setup.sh status     # статус контейнера
./setup.sh stop       # остановить
./setup.sh reinstall  # новый секрет + переустановка
```

## Настройки

Скопируйте `.env.example` → `.env` или задайте переменные перед запуском:

| Переменная   | По умолчанию     | Смысл                          |
|--------------|------------------|--------------------------------|
| `VPS_IP`     | авто             | Публичный IP сервера           |
| `MTG_PORT`   | `443`            | Порт прокси                    |
| `MTG_DOMAIN` | `cloudflare.com` | Домен для маскировки Fake-TLS  |
| `MTG_SECRET` | генерируется     | Секрет `ee…` (не придумывать)  |

Пример другого порта:

```bash
MTG_PORT=8443 ./setup.sh
```

## Подключение вручную

Telegram → **Settings → Data and Storage → Proxy → Add Proxy → MTProto**:

- Server = IP из `./setup.sh link`
- Port = `443` (или ваш `MTG_PORT`)
- Secret = значение `MTG_SECRET` из `.env`

## Файлы

| Файл                 | Назначение                          |
|----------------------|-------------------------------------|
| `setup.sh`           | Установка и управление              |
| `docker-compose.yml` | mtg + автообновление (Watchtower)   |
| `.env`               | IP, порт, секрет (не коммитить)     |
| `config.toml`        | Конфиг mtg (не коммитить)           |
| `proxy-link.txt`     | Готовая `tg://` ссылка              |

## Безопасность

- Не публикуйте `.env` / `config.toml` / секрет
- Меняйте секрет (`./setup.sh reinstall`), если ссылка утекла
- Используйте только свой VPS — чужие публичные списки прокси часто сниффят трафик
