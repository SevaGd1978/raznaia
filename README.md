# Telegram MTProto Proxy

Готовый прокси для подключения Telegram через протокол MTProto. Работает в
официальном Docker-образе Telegram, сам создаёт секрет и сохраняет его между
перезапусками.

## Что понадобится

- VPS с публичным IPv4-адресом;
- Linux и Docker с плагином Compose;
- открытый входящий порт `443/tcp`;
- корректные дата и время на сервере.

Если порт 443 занят, при запуске можно выбрать другой, например:

```bash
MTPROXY_PORT=8443 ./mtproxy start
```

В таком случае откройте `8443/tcp` в firewall и у провайдера VPS.

## Запуск

```bash
chmod +x mtproxy
./mtproxy start
```

После запуска скрипт выведет ссылку вида `tg://proxy?...`. Откройте её на
устройстве с Telegram и подтвердите добавление прокси.

Полезные команды:

```bash
./mtproxy link      # снова показать ссылку
./mtproxy status    # состояние контейнера
./mtproxy stats     # статистика подключений
./mtproxy logs      # журнал в реальном времени
./mtproxy restart   # перезапуск
./mtproxy update    # обновить образ и перезапустить
./mtproxy stop      # остановить
./mtproxy remove    # удалить контейнер, но сохранить секрет
```

Секрет хранится в Docker volume `mtproto-data`. Команда `remove` его не
удаляет. Чтобы безвозвратно удалить прокси вместе с секретом:

```bash
docker compose down -v
```

## Настройка

Переменные задаются перед командой:

```bash
WORKERS=4 SECRET_COUNT=2 ./mtproxy start
```

| Переменная | По умолчанию | Назначение |
| --- | ---: | --- |
| `MTPROXY_PORT` | `443` | Внешний TCP-порт |
| `WORKERS` | `2` | Число рабочих процессов |
| `SECRET_COUNT` | `1` | Число ключей доступа (от 1 до 16) |

Для обычного личного прокси значения по умолчанию менять не нужно.

## Эксплуатация

Telegram рекомендует перезапускать контейнер примерно раз в сутки, чтобы
обновлять адреса своих серверов. Добавьте в root-crontab (`sudo crontab -e`):

```cron
17 4 * * * cd /полный/путь/к/проекту && docker compose restart mtproto
```

Проверяйте, что системные часы отличаются от UTC не более чем на пять секунд.
Для статистики и регистрации прокси можно использовать
[@MTProxybot](https://t.me/MTProxybot).

## Ограничения безопасности

- MTProto Proxy предназначен только для трафика Telegram, это не VPN и не
  обычный HTTP/SOCKS-прокси.
- Ссылка содержит секрет доступа. Не публикуйте её, если прокси должен быть
  личным.
- Не публикуйте служебный endpoint статистики в интернет.
