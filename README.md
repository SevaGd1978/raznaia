# raznaia

Репозиторий содержит веб-модуль выставления счетов **СчётМастер**.

Перейдите в каталог `invoice-app` и следуйте инструкциям в `invoice-app/README.md`.

Кратко:

```bash
cd invoice-app
npm install
npm run dev
```

Модуль поддерживает:

- работы в нормочасах;
- запасные части;
- НДС 22%;
- предпросмотр и печать счёта.
