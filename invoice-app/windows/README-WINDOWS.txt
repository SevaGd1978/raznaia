СчётМастер — установка на Windows
=================================

Содержимое пакета
-----------------
- install.bat      — установка в профиль пользователя + ярлыки
- start.bat        — запуск без установки (portable)
- uninstall.ps1    — удаление программы
- app\             — приложение
- runtime\         — встроенный Node.js для Windows + зависимости

Быстрый старт
-------------
1. Распакуйте ZIP-архив
2. Запустите install.bat
3. Откройте ярлык «СчётМастер» на рабочем столе

Или без установки: start.bat

Вход
----
Админ:  login admin
Пароль: AdminRaznaia2026

Регистрация обычных пользователей — на экране входа.

Данные
------
База и настройки: %APPDATA%\SchetMaster\

Сборка Setup.exe (опционально)
------------------------------
На Windows с установленным Inno Setup:
  ISCC.exe windows\schetmaster.iss
