# СчётМастер

Веб-модуль выставления счетов для сервисных работ.

## Возможности

- Черновики счетов с автосохранением в `localStorage`
- Позиции **работ в нормочасах** (часы × ставка)
- Позиции **запасных частей** (количество × цена)
- Автоматический расчёт **НДС 22%** и итога к оплате
- Предпросмотр и печать счёта

## Запуск

```bash
cd invoice-app
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

Тесты расчётов:

```bash
npm test
```

## Формулы

- Работа: `нормочасы × ставка`
- Запчасть: `количество × цена`
- Без НДС: сумма всех позиций
- НДС: `без НДС × 0.22`
- К оплате: `без НДС + НДС`
