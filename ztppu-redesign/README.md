# Редизайн ztppu.ru — прототип

Готовый лендинг в папке `ztppu-redesign/` на основе конкурентного разбора (Сайверхот + аудит собственного сайта).

## Как открыть

Откройте `ztppu-redesign/index.html` в браузере или поднимите статический сервер:

```bash
cd ztppu-redesign && python3 -m http.server 8080
```

## Что изменено в стратегии сайта

| Было (слабость) | Стало |
|---|---|
| «Самые быстрые / технологичные в СНГ» | **Дата отгрузки в договоре** — проверяемое обещание |
| Закрытый прайс только через форму | **Открытые ориентиры цен** + точный расчёт в КП |
| Акцент «дешевле на 15–25%» | **Заводская цена полного цикла** без демпинг-риторики |
| Слабый ответ на жалобы «менеджер пропал» | Блок **статус после оплаты** + процесс из 4 шагов |
| Гиперболы и разные цифры мощности | Только **проверяемые факты** (линии, роботы, парк, площадь) |
| Hero перегружен обещаниями | Один бренд, один оффер, один CTA, full-bleed визуал |

## Структура страницы

1. Hero — бренд + оффер «дата в договоре»
2. Trust strip — 4 обязательства
3. SLA — почему выбирают повторно
4. Продукция — строки, не карточки
5. Цены — таблица-ориентир + экономика полного цикла
6. Производство — факты без «№1 в мире»
7. Процесс — от заявки до отгрузки
8. Объекты — сроки и объёмы
9. FAQ — возражения снабжения/СБ
10. Форма КП

## Внедрение на боевой сайт

1. Подключить форму к CRM (Bitrix24 / email / call-центр).
2. Подставить **реальные актуальные цены** в таблицу (сейчас — рыночные ориентиры).
3. Заменить Unsplash на собственные фото цеха / отгрузки / объектов.
4. Свести ztppu.ru и pzpt.ru к **одному сообщению**: срок + цена завода + статус заказа.
5. Добавить на прод: политику ПДн, реквизиты, сертификаты, скачивание каталога PDF.
6. Для SEO сохранить посадочные под типы труб, но вести их в новый оффер (не в «мы дешевле всех»).

## Рекомендации после запуска сайта

- В договоре реально фиксировать дату и условия компенсации — сайт без операционки не сработает.
- Дать менеджерам шаблон еженедельного статуса заказа.
- Убрать с маркетинга фразы «быстрее любого конкурента» / «нет аналогов в мире».
