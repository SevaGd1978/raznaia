# Руководство пользователя — Raznaia TMS

Краткая инструкция для логиста / диспетчера.

## Вход

1. Откройте приложение в браузере (например http://localhost:5173).
2. Введите email и пароль.
3. Демо-доступ после `seed.py`: **admin@raznaia.local** / **admin123**

## Главная (Дашборд)

- **Всего заказов** — количество в системе.
- **На сегодня** — заказы с датой погрузки сегодня.
- **Суммарная маржа** — разница между ставками клиентов и перевозчиков.
- Блок **«Заказы по статусам»** — быстрый обзор загрузки.

## Заказы

### Создание

1. **Заказы → + Новый заказ**
2. Выберите клиента, укажите маршрут, даты, ставки.
3. Нажмите **Создать заказ**.

### Назначение перевозчика

1. Откройте заказ из списка.
2. Выберите **перевозчика** и **ТС**.
3. **Сохранить**.

### Статусы

| Статус | Значение |
|--------|----------|
| Черновик | Заказ создан, не подтверждён |
| Подтверждён | Согласован с клиентом |
| Назначен | Есть перевозчик |
| В пути | Груз в дороге |
| Выполнен | Доставка завершена |
| Закрыт | Документы и оплата закрыты |
| Отменён | Заказ отменён |

Смена статуса — блок **«Смена статуса»** в карточке заказа.

### Заявка (PDF)

Кнопка **«Скачать заявку (PDF)»** — печатная форма для перевозчика.

## Справочники

- **Клиенты** — заказчики перевозок.
- **Перевозчики** — исполнители.
- **Транспорт** — ТС, привязанные к перевозчикам.

В каждом разделе: **+ Добавить** через форму в модальном окне.

## Отчёты

1. **Отчёты** в меню.
2. Выберите период (с / по).
3. Просмотрите таблицу и итоги (оборот, расход, маржа).
4. **Скачать CSV** — выгрузка в Excel.

## Типовой сценарий дня

1. Открыть дашборд — посмотреть заказы на сегодня.
2. Создать новые заказы от клиентов.
3. Назначить перевозчиков, сменить статус на **Назначен**.
4. Отправить PDF-заявки.
5. По мере рейсов — **В пути** → **Выполнен** → **Закрыт**.
6. В конце месяца — отчёт за период.

## Поддержка

- API документация: `/docs` на backend.
- Ошибка входа — проверьте, что backend запущен и выполнен `seed.py`.
