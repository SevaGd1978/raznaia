# Чек-лист интеграций

План подключения внешних систем к Raznaia TMS (после MVP v1.0).

**Порядок приоритетов:** 1С → ЭДО → АТИ → остальные.

---

## Общие требования (для любой интеграции)

- [ ] Описать контракт: формат данных, направление (import/export/both)
- [ ] Реализовать adapter-слой (не смешивать с domain logic)
- [ ] Логировать все обмены (request/response, timestamp, status)
- [ ] Retry при временных ошибках (3 попытки, exponential backoff)
- [ ] UI: статус последней синхронизации + ручной запуск
- [ ] Тестовый стенд партнёра перед prod
- [ ] Документация для администратора

---

## 1. 1С:Предприятие

**Назначение:** обмен контрагентами, счетами, актами, банковской выпиской.

### Подготовка
- [ ] Уточнить конфигурацию клиента (Бухгалтерия 3.0, УТ, ERP)
- [ ] Выбрать протокол: REST (1C HTTP-сервис) / CommerceML / файловый обмен
- [ ] Получить тестовую базу 1С

### Контрагенты
- [ ] Export: клиенты и перевозчики из TMS → 1С
- [ ] Import: новые контрагенты из 1С → TMS
- [ ] Маппинг полей: ИНН, КПП, наименование, адрес, банк. реквизиты
- [ ] Стратегия дубликатов: match по ИНН

### Документы
- [ ] Export: счёт на оплату (реализация услуг)
- [ ] Export: акт выполненных работ / УПД
- [ ] Import: поступление услуг от перевозчика
- [ ] Связь документ 1С ↔ заказ TMS (external_id)

### Банк
- [ ] Import: выписка (CSV/1C native)
- [ ] Автосопоставление платежей со счетами

### Тестирование
- [ ] Round-trip: контрагент TMS → 1С → изменение → обратно
- [ ] Сверка сумм по 10 заказам

**Оценка сложности:** высокая · **Срок:** 2–3 недели

## Архитектура интеграционного слоя

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────┐
│  TMS Core   │────▶│ Integration Hub  │────▶│  Adapters   │
│  (domain)   │◀────│  (queue, log)    │◀────│  1C|EDO|ATI │
└─────────────┘     └──────────────────┘     └─────────────┘
```

- **Integration Hub:** Celery/RQ очередь, таблица `integration_log`
- **Adapters:** отдельный Python-модуль на каждый сервис
- **Config:** credentials в env / vault, не в коде

## Чек-лист перед prod-интеграцией

- [ ] Тест на sandbox пройден ≥10 операций без ошибок
- [ ] Rollback-план при сбое обмена
- [ ] Алерт при 3+ последовательных ошибках sync
- [ ] Инструкция для клиента (настройка ключей)
- [ ] Поддержка: типовые ошибки в FAQ
